# Prompt 架构设计文档

> 所属项目：project_002_多模态Agent智能面试评估系统
> 版本：v1.0 | 日期：2026-06-25

---

## 一、Prompt 体系总览

系统采用**分层 Prompt 架构**，共 4 层：

```
┌─────────────────────────────────────────┐
│ Layer 1: System Prompt (角色定义)        │  ← 固定模板
├─────────────────────────────────────────┤
│ Layer 2: Decision Prompt (策略注入)      │  ← Agent 决策驱动
├─────────────────────────────────────────┤
│ Layer 3: Context Prompt (知识库注入)     │  ← RAG 检索结果
├─────────────────────────────────────────┤
│ Layer 4: Conversation (对话历史)         │  ← 多轮上下文
└─────────────────────────────────────────┘
```

---

## 二、Layer 1 — System Prompt（角色定义）

### 模板

```
你是一个专业的AI面试官，正在面试「{position}」岗位的候选人。
你的任务是根据候选人的回答，动态决定下一题问什么。
保持专业、友善的语调。每轮只问一个问题。
```

### 设计原则

| 原则 | 说明 |
| ---- | ---- |
| 角色锚定 | 第一句明确"AI面试官"身份，防止角色漂移 |
| 任务聚焦 | "动态决定下一题"强调自主性，非预设题库 |
| 语调约束 | "专业、友善"防止过于冷漠或随意 |
| 节奏控制 | "每轮只问一个问题"防止一次抛多个问题 |

---

## 三、Layer 2 — Decision Prompt（策略注入）

### 五路决策模板

| 决策 | Prompt 注入 | 触发条件 |
| ---- | ----------- | -------- |
| 深挖弱点 | `候选人在某些维度回答不够深入，请针对弱点追问细节。` | weak_count >= 2 |
| 转话题 | `请换一个不相关的话题方向，扩大考察范围。` | weak_count >= 3 或表现优秀 |
| 给提示 | `候选人似乎遇到了困难，请给出一个温和的引导性提示。` | overall < 35 |
| 结束 | `请礼貌地结束面试，感谢候选人的参与。` | turn >= 12 或连续 3 轮 < 35 |
| 开场 | `请做开场白，介绍面试流程，请候选人先自我介绍。` | turn == 0 |

### 压力感知注入

```
注意：候选人压力水平较高（{pressure}），请保持鼓励和耐心。
```

> 当 `pressure > 0.5` 时注入，触发后决策优先级不变，仅调整语调。

## 四、Layer 3 — Context Prompt（知识库注入）

### 注入格式

```
参考知识（可用于出题或评价）：
- {knowledge_item_1}
- {knowledge_item_2}
- ...
```

### 检索策略

| 决策类型 | 检索目标 | 数量上限 |
| -------- | -------- | -------- |
| 深挖弱点 | 弱点维度相关知识（如"关键词覆盖_前端开发工程师"） | 3 条/维度 |
| 转话题 | 未覆盖话题的知识 | 2 条 |
| 给提示 | 基础知识（{position}_基础概念） | 2 条 |
| 结束 | 不检索 | 0 条 |

### 知识库结构

```
{position}_{dimension} → [知识点列表]

示例：
前端开发工程师_关键词覆盖 → [
    "React通过虚拟DOM Diff算法减少真实DOM操作",
    "Webpack核心概念：entry/ output/ loader/ plugin",
    ...
]
```

## 五、Layer 4 — Conversation（对话历史）

### 组装方式

```python
messages = [
    {"role": "system", "content": system_prompt},     # L1+L2+L3
    {"role": "user", "content": "开始面试"},            # 首轮
    {"role": "assistant", "content": "请自我介绍..."},  # AI回复
    {"role": "user", "content": "我擅长React..."},      # 当前轮
]
```

### 窗口策略

| 参数 | 值 | 说明 |
| ---- | ---- | ---- |
| 最大轮次 | 12 | 超过自动结束 |
| 历史保留 | 全部 | 当前为 MockLLM，ChatGLM 上线后改为最近 10 轮 |
| Token 预算 | 未限制 | ChatGLM 上线后限制 4096 |

## 六、多模态上下文

### 文本分析注入（隐式）

文本 5 维分析结果通过 `analysis_summary` 字段传入 Agent 决策层，**不直接注入 Prompt**，避免干扰 LLM 的自然对话能力。

### 语音/视觉注入（待实现）

语音和视觉分析结果暂不注入 Prompt，仅用于 Agent 决策和报告生成。未来可在压力 > 0.7 时注入"候选人看起来有些紧张"等温和提示。

## 七、Prompt 安全策略

| 策略 | 实现 |
| ---- | ---- |
| 角色锚定 | System Prompt 第一条即锁定身份 |
| 防越狱 | 不暴露内部评分/决策逻辑给候选人 |
| 防注入 | 用户输入仅放在 user role 中，不拼接 system prompt |
| 输出过滤 | "每轮只问一个问题"限制输出长度 |
