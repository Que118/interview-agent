## 第一章：绪论

### 1.1 研究背景与意义
- 传统面试的痛点：主观性强、效率低、缺乏标准化
- AI 面试工具现状：多数为预设题库 + 固定评分，缺乏动态适应性
- 多模态 AI 技术的成熟：LLM + 语音识别 + 视觉分析的融合趋势

### 1.2 国内外研究现状
- 智能面试系统：HireVue、myInterview 等商业方案
- 多模态情感计算：语音情感识别、面部表情分析
- Agent 决策系统：LangGraph、AutoGPT 等自治 Agent 框架

### 1.3 论文主要工作
- 设计并实现18维多模态面试评估体系
- 构建基于状态机的 Agent 动态出题系统
- 实现文本/语音/视觉三模态融合分析
- 完成知识库驱动的问题生成与追问策略

## 第二章：相关技术综述

### 2.1 大语言模型与 Agent 技术
- ChatGLM-6B 模型架构与能力
- LangGraph 状态机与 Agent 编排
- Agent 决策模式：感知→分析→决策→执行

### 2.2 多模态分析技术
- 文本分析：关键词提取、语义理解、结构分析
- 语音分析：Whisper 语音识别、librosa 声学特征提取、parselmouth 韵律分析
- 视觉分析：MediaPipe Face Mesh 面部关键点检测、DeepFace 表情识别

### 2.3 检索增强生成（RAG）
- ChromaDB 向量数据库
- text2vec-large-chinese 中文语义嵌入
- 知识库构建与检索策略

### 2.4 Web 应用技术栈
- FastAPI 异步后端框架
- Next.js 14 前端框架
- Celery + Redis 异步任务队列

## 第三章：系统设计

### 3.1 需求分析
- 功能需求：岗位选择、动态出题、多模态评估、报告生成
- 非功能需求：实时性（<3s/轮）、隐私合规（视觉浏览器端处理）、可扩展性

### 3.2 系统架构
- 三层架构：感知层 → 融合层 → Agent 决策层
- 系统架构图（Mermaid 或框图）
- 技术栈选型理由

### 3.3 18维评价体系设计
| 层级 | 维度 | 分析方法 |
|------|------|----------|
| 文本层 (5维) | 关键词覆盖、结构逻辑、术语准确、简历匹配、信息密度 | jieba+sklearn+ChatGLM |
| 语音层 (5维) | 语速节奏、停顿卡壳、语调情感、流利重复、音量清晰 | Whisper+librosa+parselmouth |
| 视觉层 (4维) | 眼神注意、面部表情、头部手势、形象背景 | MediaPipe+DeepFace |
| 融合层 (4维) | 内容情感一致性、压力评估、连贯时间、个性化出题 | 跨模态融合算法 |

### 3.4 Agent 决策系统设计
- 面试状态机：InterviewState 数据结构
- 决策策略：7条优先级规则
- 知识检索器：按岗位×维度组织，按决策类型检索

### 3.5 数据库设计
- 知识库结构：岗位_维度 → 知识点列表（353条）
- 会话状态管理

## 第四章：系统实现

### 4.1 开发环境与工具
- 开发环境：Python 3.13, Node.js 20
- 关键依赖：FastAPI, LangGraph, ChromaDB, MediaPipe

### 4.2 后端核心模块
- LLM 抽象层：策略模式，ChatGLM + MockLLM 双实现
- 文本5维分析管道：关键词库匹配、结构信号检测、术语加权评分
- 语音5维分析管道：VAD能量检测、过零率分析、音高变化追踪
- 视觉4维分析管道：FaceData 特征提取、多维度独立评分
- 18维融合层：跨模态一致性、压力指数、时间连贯性、个性化综合分

### 4.3 Agent 决策引擎
- 状态追踪：弱点命中、话题覆盖、压力累积
- 决策规则：开场→深挖/转题/给提示/结束
- 知识检索：按弱点维度/未覆盖话题/基础知识分类检索

### 4.4 前端实现
- Next.js 14 App Router 结构
- ChatBox 对话组件
- MediaPipe 浏览器端人脸检测集成

### 4.5 API 接口设计
- `/api/chat`：多模态面试端点
- `/api/report/{session_id}`：面试报告端点
- 请求/响应格式说明

- 完成18维多模态面试评估体系
